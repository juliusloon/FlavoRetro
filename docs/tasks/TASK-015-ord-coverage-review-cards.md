## 范围与理由

TASK-014 的 60 条记录只有机器建议与空白标注，不便于人工逐条核对；ORD 可访问不等于黄酮/糖苷已有足够覆盖。先做开放源覆盖实测和审核准备，避免让所有者无目标地重搜商业数据库。此 TASK 是路线中人工 gold 工作的准备阶段；实际独立人工审核与 gold 冻结仍未授权执行。

1. 冻结 ORD 官方镜像 revision，下载并校验 USPTO 汇总 Parquet（约 1.1 GB）及冻结镜像中的其余 52 个 Parquet（合计约 144 MB），逐行解析与母核候选扫描；保留原始文件、失败、来源、零/缺失和局限。最多 2 GB 源下载、4 个工作进程；遇到授权限制停止该来源。不将 USPTO 子集结果写成全 ORD 结论。
2. 用 TASK-014 冻结的 9 母核规则比较覆盖、糖苷候选、精确反应重合及分类缺口。新数据只进入独立 raw/candidate 目录，不改变 v3/active/release，不接入 MCTS，不声称无训练泄漏。
3. 为现有 60 条样本生成本地离线 HTML 审核卡：反应结构、原始来源/定位、实验描述、收率、机器建议与待核对项；支持筛选、填写、导入导出。Crossref 元数据匹配只用于出处导航，不代替原文/实验审核；不得自动填人工结论。
4. 汇总实际缺口，形成小批量、定向 SciFinder 检索清单及可接受导出格式。不访问 Reaxys，不调用用户商业数据库身份，不要求用户先自行搜全量数据。

- 出处与适用范围明确；覆盖输出有可重算的脚本、候选记录与机器状态，无科学准入升级。
