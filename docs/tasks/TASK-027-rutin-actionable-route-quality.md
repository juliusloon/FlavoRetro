## 目的、范围与理由

把“能区分候选”推进为“能优先给出值得研究的化学路线”。首跑显示保护/脱保护变体、重复库存小分子及未解决糖基溴供体可支配排名；重复叶抬分已在TASK026修正，化学路线仍需独立核查。后续不能靠增加分数位数或把游离糖/母体糖当活化供体来宣布闭合。

1. P0（先诊断）：逐步核对芦丁前25及高分近邻，明确真实成键/保护基步骤、重复操作、末端结构、糖连接位点、供体活化形式与完整立体。图拓扑标注只作定位。现有文献/糖苷库对该目标是否有合法精确或受限范围动作必须逐条实测，不能从库名推断覆盖。
2. P1（资源与化学）：建立有一手来源、明确底物/糖供体/位点/异头构型/保护状态的参考路线；芦丁关键糖苷/糖间成键及糖供体制备分别追溯。库存按精确全结构身份，记录当前供应证据日期；缺供体则输出明确的未完成子目标，不以价格/母体糖名替代证据。
3. P2（路线约束）：核查保护/脱保护的必要性、反应方向、可逆来回变换及副试剂重复；以反应中心和骨架转换聚类，评估前5/前25是否仅是同一思路的近重复。任何forward检查、图重构、来源实例匹配和实验可行性分别记录。
4. P3（校准与对照）：冻结原MCTS回传、新排序、新回传三项分离的开发对照，检验究竟改善搜索还是仅改变展示。权重不使用本例单目标反复追调；至少芦丁及2个来源合格的关联糖苷、每目标2个技术seed，来源组/曝光状态先冻结。独立迁移继续沿用TASK017的门，不借开发示例升级。

## 验收

- 芦丁至少得到两种骨架/关键断键不同的可解释候选思路，或用来源和模板适用性证明缺口；同一保护/脱保护次序的变体不充作独立路线。
- 对优先路线逐步给出精确前体、方向、保护状态、糖供体形式、位点/立体、来源及条件证据。未报告收率/选择性保持未知；来源中的0保留0。每个未解决叶都有下一步子目标和未闭合原因。
- 展示的闭合路线逐叶符合精确库存；原文匹配与新底物假设分别标记。无一手支持/未检查的关键步骤不得被称为可执行方案。
