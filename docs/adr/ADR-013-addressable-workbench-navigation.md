# ADR-013 工作台使用可寻址的层级子页面

状态：accepted。日期：2026-10-24。负责人：Cano。审批：agent_delegated，human_reviewed=false。任务：[TASK-041](../tasks/TASK-041-addressable-subpages.md)。

## 背景

原工作台的五个栏目及教学内部区域只切换DOM可见性，不改变地址或浏览器历史。浏览器返回会离开整个工作台，刷新及复制链接无法恢复所在子页。既有HTTP入口是包内静态资产白名单，部署无前端构建步骤。

## 决定

保留同一静态壳与原生JS，以`#/`后的层级路径表示子页面；用pushState记录导航，用popstate/hashchange恢复，用replaceState规范化默认/越界参数。点击同一地址不重复压栈。主导航、教学分区与四个工具改为真实链接，保留方向键、Home/End、Enter/Space与原生新标签行为。浏览器返回只遍历实际访问历史，不拦截离站。

五个主入口是`#/search`、`#/history`、`#/resources`、`#/literature`与`#/governance`。教学细分为`examples/<类型>`、`principles/<原理>`和`tools/<lessons|papers|practice|evidence>`；资源记录使用`#/resources/<id>`，运行及路线使用`#/search?run=<id>&route=<序号>`。可分享的筛选、分页、A/B与来源定位进入URL；完整搜索草稿及显式预算覆盖集合存sessionStorage，滚动存各历史条目的state。存储不可用时仍可导航，关闭会话后不保证草稿保留。

URL恢复只读取现有GET接口；保存运行仍经原完整性核验，不重新发起搜索。导航代次及对照读取代次丢弃旧异步响应，避免延迟请求覆盖新页面。教学内容、库存/数据身份和原始运行/导出不因导航改变。旧`?run=`入口转换为新地址。

## 备选方案

- 继续仅切换DOM：改动少，但无法解决浏览器历史与重新进入。
- pathname路由及HTTP回退：地址整洁，但需调整运行中服务的白名单/部署入口，也会改变包安装后的静态路径合同。
- 新框架与独立HTML：可进一步拆分代码，但当前无此依赖，增加构建与重复状态管理成本。

选择hash路径，使现有服务与安装包都可直接刷新/进入，改动限于前端及镜像。

## 影响与风险

URL包含`#`；静态壳仍共用同一app.js，逻辑子页不是多个独立HTML。sessionStorage只在当前浏览器会话内保存草稿，URL自身已足够恢复各可分享子页。仅有入口地址的初次访问不会凭空制造上一页，返回仍遵循浏览器正常语义。

## 复审条件

若需要服务端渲染、搜索引擎索引、按子页权限隔离或独立代码加载，再评估pathname路由和代码拆分，继续兼容已有hash及run分享链接。

## 2026-10-24 界面修订（TASK-042）

用户要求移除新增面包屑栏，现已删除该视觉入口与占位；层级地址、浏览器历史、直接进入、标题和状态分工决定继续有效。页面内使用原主/教学导航切换，返回/前进使用浏览器历史。此修订不回写TASK041当时验收。
