# ADR-005：运行工作区、不可变资源与派生查询索引

- 状态：accepted
- 日期：2026-09-26
- 批准：所有者明确批准 TASK-012 全范围（human_direct 工程授权）

## 背景

包以父目录为 ROOT，配置/前端没进入 wheel，运行依赖 checkout 与旧 Conda。数据版本在多模块硬编码 v1，SQLite 查询层缺失；来源定位 v2 与活动 v1 并存。工程可运行并不足以独立交付。

## 决定

1. 工作区显式由 --workspace / FLAVORETRO_WORKSPACE 选择，CLI/API/worker/评估共用；安装包只保存代码、前端与默认配置，可写输出全部在工作区。源码 checkout 的默认路径保持兼容；安装包默认用户数据目录。
2. 不可变 JSON 为唯一资源事实源，active.json 只绑定已验收版本及 manifest 哈希。新 v3/replay-v3 用同构建器逐字节回放，保留 v1/v2；定位元数据不晋级内容证据。
3. SQLite 为可重建只读查询索引，保留原记录 JSON、sources、outcomes、QC、schema 与文件哈希；不允许 UI 或数据库编辑独立改事实。版本/索引错配失败，不自动回退。
4. web/configs 为编辑源，assets 内为包交付副本；自动测试比较字节一致。选受控副本而非依赖安装目录外的 data-files，确保 wheel 在仓库外能运行。
5. 搜索与开发对照在同一 HTTP 服务共享门控；历史读取明确 explicit_saved_run；开发对照有持久化进度/失败，重启不伪装正在执行。

## 备选方案与理由

- 固定 checkout：不能解决安装/迁移，拒绝。
- 外部 PostgreSQL 与服务端状态库：当前 3,059 条数据不需要额外服务；SQLite 足以满足溯源和查询，暂不引入。
- 同时编辑 JSON 和 SQL：形成两个事实源，拒绝。
- 安装包携带数据/模型：违背许可和治理边界，拒绝。
- 从未知 classification 推断专属反应家族：缺少标签证据，拒绝；保持 Unknown。

## 影响、风险与复审条件

新增包副本需在前端/配置改动时同步并由测试阻止漂移；资源或 schema 变化须建新版本。锁清单固定当前 Linux/Python 3.10 的解析结果，不保证其他平台。服务器为本机研究使用，同一进程门控不等于跨服务实例调度。

未来数据规模、正式部署或独立化学标签就绪时重新评审；工程通过不自动关闭科学门槛。
