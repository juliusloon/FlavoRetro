# ADR-010：连续研究优先级与全前沿排序

日期：2026-10-23；状态：Accepted（agent_delegated，human_reviewed=false）；依据：TASK-026。

原输出score是steps + 2×未解决末端数 + 5×已知危险数 + 未指定末端立体数，整数且低分优先。提取时先按闭合/末端数/深度/SMILES截取25条，无法保证展示的是值得优先研究的路线。

采用research-priority-v2（首跑v1的重复库存叶偏差已由TASK-026-P1纠正）：对MCTS实际生成的全部非根、已闭合或无子节点前沿提取路线，按结构身份去重后评分，最后才截取top_k。所有候选的ID、原始全精度分数、组成、排名及旧成本保存在candidate_ranking，界面4位小数不影响后端全精度排序。同分保持真实并列，以结构哈希稳定排列，不引入随机抖动。

各叶子的透明结构负担为重原子数×(1+0.08×环数+0.04×立体中心数)。按规范化完整立体SMILES对叶去重，仅在库存覆盖/结构负担中使用唯一结构；实际图、投料次数、成本、步数和简洁项保留原重数。未解决唯一叶负担总和除以目标负担得B；前体简化项为exp(-B)，不是独立合成可及性模型。库存覆盖按唯一叶重原子数加权；相同原料重复出现不增加覆盖。首跑v1仅做重原子加权，仍会被重复乙酸酐末端抬分；首跑事实和原方法字节保留，不能作为最终方法成绩。模型支持为已知原始策略先验的几何均值×先验覆盖率，非反应成功率；0保持0，缺失记录null、缺失部分无支持，不重分配权重。路线简洁为1/(1+0.15×步数+0.10×最大深度+0.05×额外末端数)。

Q=(0.35×库存覆盖+0.25×前体简化+0.25×模型支持+0.15×路线简洁)×exp(-0.25×已知危险数-0.08×未指定立体中心数)。候选闭合score=60+40Q，否则score=60Q。高分优先；两段明确区分库存闭合与尚未闭合，但均不证明可采购、完整条件、选择性或独立化学有效性。未知危险无安全认证；仅对已有明确危险标记扣分。

optimized两条既有MCTS树在配置research_reward=true时用相同优先级/100做真实回传，继续保留原UCT/PUCT及节点/环路约束；native搜索回传不变，最终候选采用相同排序口径。本方法改搜索轨迹，因此旧TASK022成绩不是当前新算法的验收；未经新受控评价，不主张搜索性能或化学质量提升。

历史文件保持原字节；saved_run响应独立research_ranking展示投影仅重排当时已保存的路线，不补出历史未保存候选。原result和manifest及导出保持原记录。当外部旧包络没有投影时，界面明确标记旧成本的单调高分转换。研究者界面显式白名单呈现结构/原文条件/收率/冲突/来源，不渲染原始JSON、运行耗时、配置、哈希或工程评测入口；审查数据仍存本地运行文件与导出。

本轮权重和结构负担未经独立化学校准。下一任务应以真实目标、非平凡关键断键和路线可实现性验证，不以分数去重率代替科学有效性。

TASK-026-P1纠偏的验收包含相同唯一库存集合下的变形测试：重复库存叶不提高覆盖或前体简化项，额外路线长度降低分数；真实第二次芦丁使用v2。两次搜索轨迹不同，不能把候选数/耗时之差解释为独立改进。
