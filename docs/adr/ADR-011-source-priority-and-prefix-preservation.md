# ADR-011：来源优先级、结构分组与真实前缀保留

日期2026-10-23；Accepted（agent_delegated，human_reviewed=false）；依据TASK027、P3冻结方案及P4/P5自检决定。

现有整数/连续代理成本可能让保护调整或副原料支配候选排序；只提取末端前沿也会在继续搜索后丢掉已经生成的、有用的未闭合前缀。当前采用research-priority-v4与all_generated_prefixes_v1，仍逐次新建MCTS。

1. 保留每个实际创建的非根MCTS节点对应路径，不从文献参考树拼接未生成步骤。frontier_count仍指真实前沿，extracted_node_count指提取的所有非根节点；结构去重后按分数排序，完整candidate_ranking不删。
2. 唯一叶库存覆盖28%、结构简化20%、模型先验20%、路线简洁12%、精确来源支持20%；已知危险、未指定碳立体及O-乙酰保护调整分别指数扣分。来源支持是命名实例/当前审核记录支持，不等于条件完备或独立实验正确；作者摘要与全文范围在显示中分开，缺失先验不补概率。
3. 碳立体缺失参与0.08惩罚；RDKit杂原子立体标记另列，保持未知、不补构型，不将UDP中两个P标记描述为糖异头碳配置缺失。原总标记和legacy_cost保留原口径。结构负担仍是未校准透明代理，不能宣称为独立合成可及性模型。
4. 仅对严格O-乙酰酯基去修饰后计算非保护转换边的结构组；不删除甲醚、苄基、糖基、活化卤素或酸酐。先选各组最高分，再补足top_k；所展示路线仍降序，组数不称机理/独立路线数。该规则不排除未证明无效的化学候选。
5. 当前精确来源库10→13记录，三条新增只重建命名产物/前体，不是新的泛化糖苷scope。候选库存仍17键；盐型目录、作者使用记录和数据库身份均不自动变当前供应。模板、库存、来源与独立化学分轴。
6. 旧18个v3开发cell及P4三次、P5三次分开保存，68/72资产分别留原字节快照；v4只有三目标单seed接口复验，不冒称已完成新三臂或独立迁移。独立门沿用TASK017，不因当前结果升级。

历史result/manifest和导出保持原件；历史只对已保存路线作当前展示投影，不能补称旧MCTS曾保存所有中间前缀。私有开发A/B/C由协议/代码/输入哈希绑定，公开SearchRequest不提供切换该控制的字段。
