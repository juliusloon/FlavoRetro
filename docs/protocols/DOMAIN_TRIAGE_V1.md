# TASK-014 领域定义与筛选规范 v1

版本：task014-v1。任务执行由所有者 human_direct 批准；本版本是工程冻结的研究规则，化学分类仍为 provisional，须在 TASK-015 独立审核中校准。实现字典为 configs/domain_triage.json，包内副本逐字节同步。

## 范围与标注单位

总范围覆盖黄酮相关骨架的构建、互变、取代基修饰、糖基相关转化及保护操作；糖苷为首轮重点子集。相关性单位是一次具体 reactant → product 记录，而不是标题命中、化合物身份、某篇论文或通式枚举的数量。一个记录可有多个结构/语境候选标签；它们不能作为互斥类别求和。

黄酮相关并不等于反应物和产物都必须已有黄酮母核：从开放链前体形成母核属于关注范围；相反，糖基化了其他天然产物也不因糖基存在自动成为黄酮相关反应。保护基步骤可归为路线支持步骤，不凭语境关键词成为核心反应。

## 总分类

| ID | 定义 | 机器 v1 能支持的观察 | 人工仍须确认 |
| --- | --- | --- | --- |
| scaffold_construction | 黄酮相关骨架构建 | 产物命中母核、反应物未命中 | 真实反应中心、实例、前体完整性；母核出现不保证成环 |
| scaffold_interconversion | 骨架互变 | 两侧命中母核集合不同 | 是否同一核心底物的转化，还是不同组件造成的集合变化 |
| glycosyl_related | 糖基形成、断裂、延伸或含糖结构修饰 | 同一连通分子兼有领域母核和候选糖苷连接 | O/C 连接、位点、糖身份、方向；含糖分子参与不等于发生糖基化 |
| substituent_modification | 骨架修饰 | 两侧母核集合相同、完整反应不相同 | 是否骨架保持；氧化、还原、甲基化等具体变换 |
| protection_deprotection | 保护/脱保护支持步骤 | 只输出相关语境词，不自动验证保护基反应 | 保护基身份、实际键变化和步骤作用 |
| other_related | 其他相关或方向未明 | 一侧有母核、或不变反应等边界 | 是否有效反应、逆向/降解/生物合成语境 |
| out_of_scope_or_unknown | 当前规则未命中或无法判断 | 没有本版本母核命中 | 当前未命中不能当作真负例；区分领域外、母核漏检和信息不足 |

生物催化/化学合成、来源强弱、模板适用性作为独立轴，不能代替上述领域分类。

## 母核查询与正反例

工程 v1 使用 9 个明确结构查询：黄酮、二氢黄酮、黄酮醇、异黄酮、查耳酮、二氢查耳酮、橙酮、黄烷、黄烷鎓。具体 query_smiles 保存在规则 JSON 中。不主张这些查询覆盖所有黄酮衍生物：异黄烷、重排母核、开环/稠合复杂衍生物、非典型糖和线性糖可能漏检，转入人工 unknown。黄烷等广义子图与更具体母核可重叠，故保留多标签。

正例工程控制：黄酮母核出现、黄酮连接 O-糖/C-糖、母核两侧类别变化。反例工程控制：乙醇、普通酚醚、非黄酮芳基糖苷；黄酮与另一个无关糖苷处于同一盐/混合物记录但不同连通片段，不算黄酮糖苷。橙酮查询使用 benzofuran-3-one 位置，benzofuran-2-one 对照不命中。来源身份示例参见 [PubChem flavone](https://pubchem.ncbi.nlm.nih.gov/compound/10680)；这些工程控制不构成独立化学 gold labels。

使用 RDKit 2023.9.6 本地执行。母核检索不按手性筛选；原始手性、同位素、形式电荷保留于 input_record 与规范化身份。子图命中仅表示连接模式匹配；RDKit 文档明确说明子图与手性选项的语义，见 [官方说明](https://www.rdkit.org/docs/GettingStartedInPython.html#substructure-searching)。

## 笔记 guide 身份

全部 508 条输入按原 ID 原样保存。token 命中会重新核对当前只读 MD，并记录实际命中行号与历史 reported_line，二者不能混用。249 条文本命中与 259 条未命中只说明笔记追溯状态，均未确认论文/SI。

- pattern_and_note_example_candidate：结构完整、领域母核命中、token 命中、无历史变体标记；可提供粗模式与具体笔记例子线索，仍不是实验事实。
- pattern_only：结构完整且母核命中，但 token 未匹配或带历史处理/变体；只提供粗模式，不能贡献具体实例匹配加分。
- context_only：没有本规则母核命中或结构不完整；保留全部上下文和风险，不生成结构 signature。

历史 manual_review_applied、confidence、needs_review=false 和 aizynthfinder_ready=true 原样保存在 input_record，但不继承为本轮审核或搜索准入。泛化/占位符处理、失败、原文上下文收率未归属、未指定立体等均单列风险。零产率保持零，缺失保持缺失；不从邻近段落自动填收率。

## 标准化、去重与两策略比较

标准化只对已解析具体结构生成 RDKit canonical isomeric SMILES。排序反应两侧的连通组分，去掉仅用于原子对应的 map 编号以得到结构身份；保留多重组分、方向、立体、同位素和电荷。RDKit 的常规氢表示规范化不改变保留的原始记录。不去盐、不归并互变异构体、不纠正立体、不补映射、条件或产率。失败/泛化记录使用独立 ID，不以空结构合并。

精确标准化反应只计算一次结构分类，复用到各个来源记录。每条来源、条件与收率不合并，duplicates.json 保存完整组关系。分子描述也缓存复用，不进行重复神经推理。

结构基线分 = 100×母核命中 + 40×领域糖苷连接 + 20×产物母核出现。

guide 分 = 基线分 + 20×粗 signature 命中 + 30×未带历史变体的笔记具体结构命中。

signature 仅包含反应两侧母核集合及同连通片段的候选糖苷连接家族集合，不包含映射反应中心，也不比较供体、催化剂或条件。加分是审核优先级，非概率/置信度/化学有效性。

两策略处理同一批记录，共享同一结构描述、输入版本和代码；输出完整排序及 guide_supported / outside_guide_structure / low_or_unknown 三队列。guide 不参与删除/硬过滤。解析不完整的行仍保留，可从有效组件得到有限线索，但不得产生有效 guide signature；审核样本独立覆盖它们。
